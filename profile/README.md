# 🦄 Unicorn Who Dev

**Creative software, unusual ideas, real products.**

Unicorn Who Dev is an independent software studio exploring the intersection of **audio, web technology, AI and games**.

## What we build

- 🎵 Browser-based creative tools
- 🎮 Games and interactive experiments
- 🤖 AI-assisted creation workflows
- 🌐 Web and mobile applications

## Featured

**DAWWW-CORE**  
A complete browser-first digital audio workstation built around Web Audio.

**Make My Game**  
Turn character ideas and sketches into playable game characters.

**Save My Lord**  
A fast-paced action game mixing platforming, combat and ranged gameplay.

> From experimental prototype to usable product.
