# Unicorn Who Dev organization defaults

This repository provides the public organization profile and default community-health files for repositories that do not define their own versions.

- [`profile/README.md`](profile/README.md) — organization landing page
- `profile/assets/` — organization profile artwork
- `.github/ISSUE_TEMPLATE/` — default bug, feature and documentation forms
- `pull_request_template.md` — default pull request checklist
- `CONTRIBUTING.md` — default contribution guidance
- `SECURITY.md` — default security-reporting guidance
- `SUPPORT.md` — public versus commercial support boundaries

Repository-specific files take precedence over these defaults.
